## Installation

```bash
npm install @billingos/node
```

**Requirements:**
- Node.js ≥ 18.0.0
- Your `BILLINGOS_SECRET_KEY` from the dashboard (Settings → API Keys)

---

## Initializing the Client

```typescript
import { BillingOS } from '@billingos/node';

const billing = new BillingOS({
  secretKey: process.env.BILLINGOS_SECRET_KEY!,
});
```

### BillingOSConfig

| Option | Type | Default | Description |
|---|---|---|---|
| `secretKey` | `string` | — | Your secret API key — **never expose this client-side**. Must start with `sk_live_` or `sk_test_` |
| `apiUrl` | `string` | `http://localhost:3001` | Base URL of your BillingOS backend |
| `timeout` | `number` | `30000` | Request timeout in milliseconds |
| `maxRetries` | `number` | `3` | Number of automatic retries on transient errors |

## Session Tokens

Session tokens are short-lived credentials that authorize a specific user for the BillingOS frontend SDK. Generate them server-side and pass them to `BillingOSProvider`.

```typescript
const { sessionToken, expiresAt } = await billing.createSessionToken({
  externalUserId: 'user_123',            // your internal user ID
  expiresIn: 3600,                       // seconds (min: 60, max: 86400)
  externalOrganizationId: 'org_abc',     // optional: scope to an org
  allowedOperations: ['read', 'write'],  // optional: restrict operations
  metadata: { plan: 'pro' },            // optional: attach custom data
});
```

### CreateSessionTokenInput

| Field | Type | Required | Description |
|---|---|---|---|
| `externalUserId` | `string` | ✅ | Your application's user ID |
| `expiresIn` | `number` | — | Token lifetime in seconds (default: 3600, range: 60–86400) |
| `externalOrganizationId` | `string` | — | Scopes the token to a specific organization |
| `allowedOperations` | `string[]` | — | Restrict what operations this token can perform |
| `metadata` | `object` | — | Custom key-value data attached to the token |

### SessionTokenResponse

| Field | Type | Description |
|---|---|---|
| `sessionToken` | `string` | JWT to pass to `BillingOSProvider` |
| `expiresAt` | `Date` | When the token expires |

### Revoking a Token

```typescript
await billing.revokeSessionToken('tok_abc123');
```

### Next.js App Router Example

```typescript app/api/billing-token/route.ts
import { BillingOS } from '@billingos/node';
import { auth } from '@/lib/auth'; // your auth helper

const billing = new BillingOS({
  secretKey: process.env.BILLINGOS_SECRET_KEY!,
});

export async function GET() {
  const session = await auth();
  if (!session?.user) {
    return new Response('Unauthorized', { status: 401 });
  }

  const { sessionToken, expiresAt } = await billing.createSessionToken({
    externalUserId: session.user.id,
    expiresIn: 3600,
  });

  return Response.json({ sessionToken, expiresAt });
}
```

## Customers

Manage customer records programmatically.

```typescript
// Create a customer
const customer = await billing.createCustomer({
  externalUserId: 'user_123',
  externalOrganizationId: 'org_abc', // optional
  email: 'jane@example.com',
  name: 'Jane Smith',
  metadata: { tier: 'vip' },
});

// Get by BillingOS customer ID
const customer = await billing.getCustomer('cust_abc');

// Get by your internal user ID
const customer = await billing.getCustomerByExternalId('user_123');

// Update a customer
await billing.updateCustomer('cust_abc', {
  name: 'Jane Doe',
  email: 'jane.doe@example.com',
});

// Delete a customer
await billing.deleteCustomer('cust_abc');
```

### Customer Object

| Field | Type | Description |
|---|---|---|
| `id` | `string` | BillingOS customer ID |
| `externalUserId` | `string` | Your app's user ID |
| `email` | `string` | Customer email |
| `name` | `string` | Customer display name |
| `stripeCustomerId` | `string` | Linked Stripe customer ID |
| `createdAt` | `string` | ISO 8601 creation timestamp |

## Subscriptions

```typescript
// Create a subscription
const subscription = await billing.createSubscription({
  customerId: 'cust_abc',
  priceId: 'price_123',
  metadata: { source: 'dashboard' },
});

// Get a subscription by ID
const sub = await billing.getSubscription('sub_xyz');

// Update a subscription (e.g., plan change)
await billing.updateSubscription('sub_xyz', {
  priceId: 'price_456',
  cancelAtPeriodEnd: false,
});

// Cancel a subscription
await billing.cancelSubscription('sub_xyz');

// Reactivate a canceled subscription
await billing.reactivateSubscription('sub_xyz');
```

### CreateSubscriptionInput

| Field | Type | Required | Description |
|---|---|---|---|
| `customerId` | `string` | ✅ | BillingOS customer ID |
| `priceId` | `string` | ✅ | Price ID to subscribe to |
| `metadata` | `object` | — | Custom key-value data |

### UpdateSubscriptionInput

| Field | Type | Description |
|---|---|---|
| `priceId` | `string` | New price ID (plan change) |
| `cancelAtPeriodEnd` | `boolean` | Schedule cancellation at period end |
| `metadata` | `object` | Custom key-value data |

### Subscription Object

| Field | Type | Description |
|---|---|---|

## Webhook Verification

Verify incoming webhooks to ensure they're authentic before processing.

```typescript
import { BillingOS } from '@billingos/node';

const billing = new BillingOS({
  secretKey: process.env.BILLINGOS_SECRET_KEY!,
});

// Express example
app.post('/webhooks/billing', express.raw({ type: 'application/json' }), (req, res) => {
  const signature = req.headers['billingos-signature'] as string;

  const isValid = billing.verifyWebhook(req.body, signature);

  if (!isValid) {
    return res.status(400).send('Invalid signature');
  }

  const event = JSON.parse(req.body);

  switch (event.type) {
    case 'subscription.created':
      // provision access
      break;
    case 'subscription.canceled':
      // revoke access
      break;
  }

  res.json({ received: true });
});
```

## Error Handling

All `@billingos/node` methods throw typed errors you can catch and handle specifically:

```typescript
import {
  BillingOS,
  AuthenticationError,
  AuthorizationError,
  NotFoundError,
  ValidationError,
  RateLimitError,
  ServerError,
  NetworkError,
} from '@billingos/node';

try {
  const token = await billing.createSessionToken({ externalUserId: 'user_123' });
} catch (err) {
  if (err instanceof AuthenticationError) {
    console.error('Invalid API key');
  } else if (err instanceof AuthorizationError) {
    console.error('Key lacks permission');
  } else if (err instanceof RateLimitError) {
    console.error('Rate limited — back off and retry');
  } else if (err instanceof NotFoundError) {
    console.error('Resource not found');
  } else if (err instanceof ValidationError) {
    console.error('Invalid input:', err.message);
  } else if (err instanceof ServerError) {
    console.error('BillingOS server error');
  } else if (err instanceof NetworkError) {
    console.error('Network failure');
  }
}
```

### Error Classes

| Class | HTTP Status | Description |
|---|---|---|
| `AuthenticationError` | 401 | Invalid or missing API key |
| `AuthorizationError` | 403 | Key lacks permission for this resource |
| `NotFoundError` | 404 | Resource does not exist |
| `ValidationError` | 422 | Invalid input parameters |
| `RateLimitError` | 429 | Too many requests |
| `ServerError` | 5xx | BillingOS server error |
| `NetworkError` | — | Network or connectivity failure |
