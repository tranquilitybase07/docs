## What is BillingOS?

BillingOS is the billing layer for your SaaS product. It lets you define products and pricing, accept recurring payments through Stripe, manage customer subscriptions, and monitor revenue — all from a single dashboard with a clean SDK for your frontend and backend.

## Core Concepts

| Concept | Description |
|---|---|
| **Organization** | Your top-level workspace. All products, customers, and revenue belong to one org. |
| **Product** | A billable item you sell — one-time, recurring, or usage-based. |
| **Subscription** | A customer's active relationship with a recurring product. |
| **Checkout Session** | A secure, Stripe-powered payment flow initiated for a specific product. |
| **Customer** | A buyer in your system, linked to a Stripe customer record. |
| **API Key** | A secret key used to authenticate SDK and API calls from your backend. |

## Architecture

BillingOS is built on:

- **Next.js** — Frontend dashboard and the embedded checkout iframe
- **NestJS** — Backend REST API and webhook handler
- **Supabase** — Postgres database and auth
- **Stripe** — Payment processing via Connected Accounts

Your application integrates with BillingOS through the **React SDK** (`@billingos/sdk`) and the **Node.js SDK** (`@billingos/node`). Your users interact with the hosted checkout iframe — meaning card data never touches your servers, keeping you PCI-compliant out of the box.

```
Your App                    BillingOS
─────────           ──────────────────────────
React frontend  →   BillingOSProvider
                    PricingTable / CheckoutModal
                    ↕ iframe (PCI-compliant checkout)
Node backend    →   @billingos/node
                    createSessionToken()
                    verifyWebhook()
```
