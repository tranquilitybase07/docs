## POST /v1/checkout/create

Creates a new checkout session. Returns a session with a client secret for payment processing.

### Authentication

Requires a session token (`bos_session_...`).

### Request body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `priceId` | `string` | Yes | Price to charge |
| `customer` | `object` | No | Customer details |
| `customer.email` | `string` | No | Email address |
| `customer.name` | `string` | No | Display name |
| `customer.taxId` | `string` | No | Tax ID |
| `couponCode` | `string` | No | Discount code |
| `metadata` | `object` | No | Custom key-value pairs |
| `existingSubscriptionId` | `string` | No | For upgrades/downgrades |

### Response

```json
{
  "id": "cs_abc123",
  "clientSecret": "cs_secret_abc123",
  "amount": 2900,
  "currency": "usd",
  "product": {
    "id": "prod_123",
    "name": "Pro Plan"
  },
  "customer": {
    "email": "user@example.com"
  },
  "status": "pending",
  "expiresAt": "2025-01-15T13:00:00Z"
}
```

### Example

```bash
curl -X POST https://api.billingos.com/v1/checkout/create \
  -H "Authorization: Bearer bos_session_abc123" \
  -H "Content-Type: application/json" \
  -d '{
    "priceId": "price_pro_monthly",
    "customer": {
      "email": "user@example.com"
    }
  }'
```
