## GET /v1/checkout/:sessionId/status

Returns the current status of a checkout session.

### Authentication

Requires a session token (`bos_session_...`).

### Path parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `sessionId` | `string` | Checkout session ID |

### Response

```json
{
  "id": "cs_abc123",
  "status": "completed",
  "amount": 2900,
  "currency": "usd",
  "priceId": "price_pro_monthly",
  "product": {
    "name": "Pro Plan"
  }
}
```

### Status values

| Status | Description |
|--------|-------------|
| `pending` | Session created, awaiting payment |
| `processing` | Payment is being processed |
| `completed` | Payment successful |
| `failed` | Payment failed |
| `expired` | Session expired without payment |

### Example

```bash
curl https://api.billingos.com/v1/checkout/cs_abc123/status \
  -H "Authorization: Bearer bos_session_abc123"
```
