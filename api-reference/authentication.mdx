## Authentication methods

### Session tokens (client-side)

Session tokens authenticate a specific customer. Use them with the React SDK.

```bash
Authorization: Bearer bos_session_abc123...
```

Created via the [Node SDK](/server-sdk/session-tokens):

```typescript
const { sessionToken } = await billing.createSessionToken({
  externalUserId: "user_123",
});
```

**Scope:** Read/write for the authenticated customer only.
**Lifetime:** 1 hour by default.

### API keys (server-side)

API keys authenticate your server with full organization access.

```bash
Authorization: Bearer sk_test_abc123...
```

**Scope:** Full access to all organization data.
**Lifetime:** No expiry (revoke manually in the dashboard).

| Key prefix | Environment |
|------------|-------------|
| `sk_test_` | Development / testing |
| `sk_live_` | Production |

## Security

<Warning>
  - Never expose API keys (`sk_test_...` or `sk_live_...`) in client-side code
  - Use session tokens for browser-based API calls
  - Rotate API keys if compromised
  - Use HTTPS for all API requests
</Warning>
