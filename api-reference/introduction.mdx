## Base URL

```
https://api.billingos.com/v1
```

For local development:
```
http://localhost:3001/v1
```

## Authentication

All API requests require authentication via the `Authorization` header:

```bash
Authorization: Bearer <token>
```

Two types of tokens:
- **Session tokens** (`bos_session_...`) — for client-side SDK calls, scoped to one customer
- **API keys** (`sk_test_...` / `sk_live_...`) — for server-side calls, full organization access

## Request format

- Content-Type: `application/json`
- All request bodies are JSON
- All responses are JSON

## Response format

Successful responses:

```json
{
  "data": { ... }
}
```

Paginated responses:

```json
{
  "data": [ ... ],
  "meta": {
    "total": 100,
    "page": 1,
    "page_size": 20,
    "total_pages": 5
  }
}
```

Error responses:

```json
{
  "error": {
    "message": "Description of what went wrong",
    "code": "ERROR_CODE",
    "details": { ... }
  }
}
```
