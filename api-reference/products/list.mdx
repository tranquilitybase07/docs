## GET /v1/products

Returns all active products with their prices and features. Used by the `PricingTable` component.

### Authentication

Requires a session token (`bos_session_...`).

### Query parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `planIds` | `string` | Comma-separated product IDs to filter |

### Response

```json
{
  "products": [
    {
      "id": "prod_123",
      "name": "Pro Plan",
      "description": "For growing teams",
      "prices": [
        {
          "id": "price_pro_monthly",
          "amount": 2900,
          "currency": "usd",
          "interval": "month",
          "intervalCount": 1
        },
        {
          "id": "price_pro_yearly",
          "amount": 29000,
          "currency": "usd",
          "interval": "year",
          "intervalCount": 1
        }
      ],
      "features": [
        {
          "id": "feat_1",
          "name": "api_calls",
          "title": "API Calls",
          "type": "usage_quota",
          "properties": { "limit": 10000 }
        }
      ],
      "isCurrentPlan": false,
      "trialDays": 14
    }
  ],
  "currentSubscription": null
}
```

### Example

```bash
curl https://api.billingos.com/v1/products \
  -H "Authorization: Bearer bos_session_abc123"

# Filter specific products
curl "https://api.billingos.com/v1/products?planIds=prod_starter,prod_pro" \
  -H "Authorization: Bearer bos_session_abc123"
```

<Note>
  Prices are in cents (e.g., `2900` = $29.00). The `isCurrentPlan` field is `true` if the authenticated customer is subscribed to that product.
</Note>
