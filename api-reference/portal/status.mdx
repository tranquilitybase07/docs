## GET /v1/portal/:sessionId/status

Returns whether a portal session is still valid and active.

### Path parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `sessionId` | `string` | Portal session ID |

### Response

```json
{
  "isValid": true,
  "expiresAt": "2025-01-15T13:00:00Z"
}
```

### Example

```bash
curl https://api.billingos.com/v1/portal/portal_session_abc123/status \
  -H "Authorization: Bearer bos_session_abc123"
```
