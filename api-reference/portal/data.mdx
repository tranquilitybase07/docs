## GET /v1/portal/:sessionId/data

Returns all data needed for the customer portal — subscription details, invoices, payment methods, and available plans.

### Path parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `sessionId` | `string` | Portal session ID |

### Example

```bash
curl https://api.billingos.com/v1/portal/portal_session_abc123/data \
  -H "Authorization: Bearer bos_session_abc123"
```
