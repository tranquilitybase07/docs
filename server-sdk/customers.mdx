## createCustomer

```typescript
const customer = await billing.createCustomer({
  email: "jane@example.com",
  name: "Jane Smith",
  metadata: { plan: "pro" },
});
```

### Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | Customer email |
| `name` | `string` | No | Customer name |
| `metadata` | `Record<string, string>` | No | Custom key-value pairs |

## getCustomer

```typescript
const customer = await billing.getCustomer("cus_123");
```

---

## getCustomerByExternalId

Look up a customer by their ID in your system.

```typescript
const customer = await billing.getCustomerByExternalId("user_123");
```

---

## listCustomers

```typescript
const { data, meta } = await billing.listCustomers({
  page: 1,
  page_size: 20,
});

// data: Customer[]
// meta: { total, page, page_size, total_pages }
```

---

## updateCustomer

```typescript
const updated = await billing.updateCustomer("cus_123", {
  name: "Jane Doe",
  metadata: { company: "Acme Inc" },
});
```

---

## deleteCustomer

```typescript
await billing.deleteCustomer("cus_123");
```

## Customer object

```typescript
interface Customer {
  id: string
  email: string
  name?: string
  metadata?: Record<string, string>
  created_at: string
  updated_at: string
}
```
