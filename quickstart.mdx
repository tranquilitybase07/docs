## Prerequisites

- A BillingOS account ([sign up at billingos.mintlify.app](https://billingos.mintlify.app))
- A Stripe account (test mode is fine to start)
- A React or Next.js application

---

## Step 1: Create Your Organization

When you first log in to BillingOS, you'll be prompted to create an **Organization**. This is your top-level workspace where all products, customers, subscriptions, and revenue data live.

1. Navigate to the BillingOS dashboard.
2. Click **Create Organization**.
3. Enter your organization name and confirm.

---

## Step 2: Connect Stripe

BillingOS processes all payments through Stripe. You need to connect a Stripe account before you can accept payments.

1. In the sidebar, go to **Settings → Stripe Connect**.
2. Click **Connect Stripe Account**.
3. Complete the Stripe OAuth flow (you can use a test mode account).
4. Once connected, your Stripe account status will show as **Active**.

<Note>
  BillingOS uses Stripe Connected Accounts, which means payouts go directly to your Stripe account — BillingOS never holds your funds.
</Note>

---

## Step 3: Create a Product

1. In the sidebar, go to **Products → New Product**.
2. Fill in the product details:
   - **Name** — e.g. "Pro Plan"
   - **Description** — a short summary shown in the pricing table
   - **Pricing type** — choose Monthly, Annual, One-time, or Free
   - **Price** — e.g. $49/month
   - **Features** — bullet points shown on your pricing card
3. Click **Save Product**.

BillingOS syncs your product to Stripe automatically.

## Step 5: Add BillingOSProvider

Wrap your app (or the section that uses billing) with `BillingOSProvider`. You'll need to generate a **session token** from your backend and pass it in.

```tsx app/layout.tsx (Next.js)
import { BillingOSProvider } from '@billingos/sdk';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  // Fetch this from your backend — see Step 6
  const sessionToken = await getSessionToken();

  return (
    <html>
      <body>
        <BillingOSProvider
          apiUrl="https://your-billingos-backend.com"
          sessionToken={sessionToken}
          customerEmail={user.email}
          customerName={user.name}
        >
          {children}
        </BillingOSProvider>
      </body>
    </html>
  );
}
```

---

## Step 6: Generate a Session Token (Backend)

Install the Node.js SDK on your server:

```bash
npm install @billingos/node
```

Create a secure endpoint to mint session tokens:

```typescript app/api/billing-token/route.ts (Next.js)
import { BillingOS } from '@billingos/node';

const billing = new BillingOS({
  secretKey: process.env.BILLINGOS_SECRET_KEY!,
});

export async function GET(req: Request) {
  const user = await getCurrentUser(req); // your auth

  const { sessionToken, expiresAt } = await billing.createSessionToken({
    externalUserId: user.id,
    expiresIn: 3600, // 1 hour
  });

  return Response.json({ sessionToken, expiresAt });
}
```

<Warning>
  Never expose your `BILLINGOS_SECRET_KEY` to the browser. Always generate session tokens server-side.
</Warning>

---

## Step 7: Add the Pricing Table

Drop the `PricingTable` component anywhere you want to display your plans:

```tsx app/pricing/page.tsx
import { PricingTable } from '@billingos/sdk';

export default function PricingPage() {
  return (
    <main>
      <h1>Choose your plan</h1>
      <PricingTable useCheckoutModal={true} />
    </main>
  );
}
```

When a user clicks a plan, BillingOS opens a **secure, iframe-based checkout modal** powered by Stripe — PCI-compliant with zero extra configuration.

---

## You're Done!

Your users can now browse your pricing table and subscribe. Stripe handles the payment, BillingOS creates the subscription, and you get real-time updates via webhooks.
